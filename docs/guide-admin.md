# Guide administrateur

## Connexion
- URL : https://votre-projet.sanity.studio
- Identifiants fournis par email

## Gestion des formations
- Cliquez sur "Formation" → "Créer"
- Remplissez les champs (titre, slug, durée, prix, etc.)

## Gestion des actualités
- Utilisez l'éditeur enrichi pour ajouter du texte, des images, des vidéos YouTube

## Appels à candidatures
- Définissez une date limite et le statut (ouvert/fermé)

Les modifications sont visibles sur le site en moins d'une minute (ISR).
